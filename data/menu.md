# MENU CHÍNH THỨC QUÁN CÀ PHÊ DMP

Chào mừng đến với Cà phê DMP. Dưới đây là bảng giá và thông tin chi tiết các món trong menu.
Tất cả các món uống (trừ Espresso Single/Double và một số món đặc thù) đều áp dụng 2 kích thước:
- **Size M (Medium)**: Dung tích tiêu chuẩn 350ml.
- **Size L (Large)**: Dung tích lớn 500ml (thêm 8.000 VNĐ đến 10.000 VNĐ tùy nhóm món).

---

## I. CÀ PHÊ TRUYỀN THỐNG (VIETNAMESE TRADITIONAL COFFEE)
*Sử dụng 100% hạt Robusta Lâm Đồng phin đậm đà, chuẩn vị Việt.*

1. **Cà Phê Đen Đá (Black Coffee)**
   - Giá: Size M: 25.000 VNĐ | Size L: 33.000 VNĐ
   - Mô tả: Đậm đà vị Robusta truyền thống, thơm nồng, hậu vị đắng thanh.

2. **Cà Phê Sữa Đá (Iced Milk Coffee)**
   - Giá: Size M: 29.000 VNĐ | Size L: 37.000 VNĐ
   - Mô tả: Sự kết hợp hoàn hảo giữa cà phê phin đắng đậm và sữa đặc béo ngọt Ngôi Sao Phương Nam.

3. **Bạc Xỉu (White Coffee)**
   - Giá: Size M: 32.000 VNĐ | Size L: 40.000 VNĐ
   - Mô tả: Ít đắng, nhiều sữa tươi và chút sữa đặc, điểm xuyết hương cà phê phin thơm lừng. Thích hợp cho người không uống được cà phê đậm.

4. **Cà Phê Muối (Salted Cream Coffee)**
   - Giá: Size M: 35.000 VNĐ | Size L: 43.000 VNĐ
   - Mô tả: Món "best-seller". Lớp kem muối béo ngậy mặn nhẹ phủ trên nền cà phê phin đậm đà.

5. **Cà Phê Trứng (Egg Cream Coffee)**
   - Giá: Size M: 38.000 VNĐ | Size L: 46.000 VNĐ
   - Mô tả: Lớp kem trứng đánh bông mịn màng, thơm ngậy không bị tanh, kết hợp cà phê nóng/lạnh.

6. **Cà Phê Cốt Dừa (Coconut Coffee)**
   - Giá: Size M: 38.000 VNĐ | Size L: 46.000 VNĐ
   - Mô tả: Cà phê phin quyện cùng đá xay cốt dừa béo thơm, giải nhiệt tuyệt vời.

7. **Cà Phê Đen Nóng (Hot Black Coffee)**
   - Giá: Size M: 25.000 VNĐ | Size L: 33.000 VNĐ
   - Mô tả: Cà phê phin mộc nguyên chất pha nóng, phù hợp buổi sáng sớm.

8. **Cà Phê Sữa Nóng (Hot Milk Coffee)**
   - Giá: Size M: 29.000 VNĐ | Size L: 37.000 VNĐ
   - Mô tả: Cà phê phin pha sữa đặc uống nóng, giữ trọn hương vị đậm đà.

## II. CÀ PHÊ MÁY & Ý (ESPRESSO BASED)
*Sử dụng hạt Arabica Cầu Đất phối Robusta thượng hạng, chiết xuất bằng máy pha chuyên nghiệp.*

9. **Espresso Single / Double**
   - Giá: Single: 30.000 VNĐ | Double: 40.000 VNĐ
   - Mô tả: Cà phê chiết xuất áp suất cao, lớp crema dày mịn.

10. **Americano (Iced/Hot)**
    - Giá: Size M: 35.000 VNĐ | Size L: 43.000 VNĐ
    - Mô tả: Espresso pha loãng với nước tinh khiết, vị đắng nhẹ, thanh thoát.

11. **Latte (Iced/Hot)**
    - Giá: Size M: 45.000 VNĐ | Size L: 53.000 VNĐ
    - Mô tả: Espresso hòa quyện cùng sữa tươi thanh trùng đánh nóng/đá, vị béo nhẹ cân bằng.

12. **Cappuccino (Iced/Hot)**
    - Giá: Size M: 45.000 VNĐ | Size L: 53.000 VNĐ
    - Mô tả: Tỷ lệ cân bằng giữa Espresso, sữa nóng và lớp bọt sữa dày xốp mịn.

13. **Caramel Macchiato**
    - Giá: Size M: 49.000 VNĐ | Size L: 57.000 VNĐ
    - Mô tả: Sữa tươi vani đánh nóng, lớp Espresso đậm đà và vạch sốt Caramel ngọt ngào trên mặt.

14. **Mocha Cacao**
    - Giá: Size M: 49.000 VNĐ | Size L: 57.000 VNĐ
    - Mô tả: Sự kết hợp hoàn hảo giữa Espresso, sốt sô-cô-la đậm đà và sữa tươi.

15. **Cold Brew Truyền Thống**
    - Giá: Size M: 42.000 VNĐ | Size L: 50.000 VNĐ
    - Mô tả: Cà phê ủ lạnh trong 16 giờ, vị chua nhẹ tự nhiên của Arabica, mượt mà dễ uống.

16. **Cold Brew Cam Sả**
    - Giá: Size M: 48.000 VNĐ | Size L: 56.000 VNĐ
    - Mô tả: Cà phê ủ lạnh kết hợp nước cam tươi sảng khoái và hương sả thơm mát.

* **Topping Bổ Sung (Đồng giá 8.000 VNĐ/phần):**

  - Trân châu hoàng kim
  - Thạch cà phê / Thạch phô mai
